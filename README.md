# Stop Working — V1.0 正式版

一款 macOS 菜单栏休息提醒 + 闹钟应用。定时结束时用全屏背景遮罩铺满**所有屏幕**（主屏 + 副屏），强制你离开屏幕休息。

> 本目录为 **V1.0 正式版** 的发布与源码目录，已按规范整理。

---

## V1.0 更新内容（本次核心）

1. **多屏幕全屏覆盖**：修复了“副屏/平板不出现遮罩”的问题。现在会为每一块屏幕各建一个全屏窗口。
   - **主屏**（带菜单栏、坐标原点那块）：保留完整界面——背景图 + 倒计时动效 + 按钮。
   - **副屏**（其余所有屏幕，数量不限）：只铺背景图，没有文字、倒计时、按钮，且挡住点击。
2. **坐标精确对齐**：修复了 macOS 在非主屏（Retina）上创建窗口时坐标被重复计算、导致窗口跑到屏幕外的 bug（`setFrame(screen.frame)`）。
3. **副屏强制置顶**：改用 `orderFrontRegardless()`，菜单栏 App 也能把遮罩铺到副屏上。
4. **横 / 竖屏自适应**：副屏按自身宽高比选背景图——横屏用 `background.png`，竖屏用 `menu_bg.png`。副屏数量、混搭横竖都支持。
5. **同进同出**：主屏和所有副屏一起淡入 / 一起隐藏（0.6s）。
6. 移除了排查用的临时诊断日志，源码干净。

## 功能特性

### 计时器模式
- 设定「工作间隔」与「休息时长」，菜单栏静默倒计时。
- 时间到 → 所有屏幕铺满背景遮罩，主屏显示提醒文字与按钮。
- 点「我会好好休息」→ 进入休息倒计时；点「我不要，我要干活！」→ 立即跳过。
- 休息结束 / 跳过 → 自动进入下一轮，无限循环，直到手动停止。

### 闹钟模式
- 选择日期、小时、分钟，支持最多 5 条闹钟，可独立编辑 / 删除。
- 闹钟到时 → 遮罩弹出主屏显示当前时间 + 提醒文字；仅提醒一次，不自动重启。

### 界面
- 主屏背景图：山城石屋庭院；菜单弹窗：手绘巷弄小屋 + 毛玻璃。
- 副屏：纯背景图铺满（横竖自适应）。
- 文字带阴影，任何背景下都清晰；支持自定义提醒文字（20 字内）+ 10 句预设短语。

## 使用环境

| 项目 | 要求 |
|------|------|
| 操作系统 | macOS 15（Sequoia）或更高 |
| 芯片 | Apple Silicon / Intel |
| 权限 | 无需特殊权限（不需要辅助功能、屏幕录制） |
| 副屏 | 需为独立的「扩展显示」；镜像/同屏不会多出副屏窗口 |

> ⚠️ 由于 App 未经过 Apple 公证，首次打开请 **右键 → 打开**，不要直接双击。

## 如何编译（源码 → App）

在 `V1.0/源码/` 目录：

```bash
xcodebuild \
  -project 休息App.xcodeproj \
  -scheme 休息App \
  -configuration Release \
  -derivedDataPath build build
```

产物在 `build/Build/Products/Release/Stop Working.app`。也可直接用 Xcode 打开 `休息App.xcodeproj` 运行/归档。

## ⚠️ 开发红线（改代码前先读）

以下机制是 App 的核心，**不要改动**，否则循环会断：

- `TimerManager.swift` 里 `showBreakOverlay` 的 `onDismiss`：**先**启动 bash 子进程、**再** `terminate(nil)`。顺序不能反。
- `__AppApp.swift` 里 `-autoRestart` 参数检测、2 秒自动启动、keep-alive 保活窗口。
- `BreakOverlayManager.swift` 里窗口的 `.screenSaver` 级别、`isReleasedWhenClosed`、`collectionBehavior`。

允许自定义的方向：界面样式、提醒文字、毛玻璃效果、背景图、时间选择器、遮罩透明度等。
