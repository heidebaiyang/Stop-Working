# Stop Working — 计时循环逻辑文档（V1.0）

## 一、循环整体流程

```
用户点「开始做牛马」
  → 工作倒计时（50 分钟 → 0）
  → 倒计时到 0 → showBreakOverlay()
  → 所有屏幕铺满遮罩，主屏显示休息 UI
  → 用户点「我会好好休息」或「我不要，我要干活！」
  → onDismiss 回调：
      ① overlayManager.hide()
      ② 启动 bash 子进程（孤儿进程，sleep 0.5 后 open -j 重启 App）
      ③ AppDelegate.allowTerminate = true
      ④ NSApplication.shared.terminate(nil)
  → bash 在 0.5s 后执行 open -j 'App' --args -autoRestart
  → App 重启，检测 -autoRestart，2 秒后 TimerManager.shared.start()
  → 新一轮工作倒计时，回到第一步。
```

## 二、关键文件

| 文件 | 作用 |
|------|------|
| `TimerManager.swift` | 工作/休息计时、bash 重启、状态管理 |
| `BreakOverlayManager.swift` | 全屏遮罩窗口的创建 / 显示 / 隐藏（多屏） |
| `BreakOverlayView.swift` | 主屏遮罩 UI + 副屏纯背景视图 |
| `__AppApp.swift` | AppDelegate：`-autoRestart` 检测、自动启动、保活窗口 |

## 三、V1.0 多屏逻辑（BreakOverlayManager）

每次 `show()` 都基于“当前屏幕布局”重建窗口，保证主屏 + 所有副屏都有窗口：

```swift
func show(...) {
    rebuildWindows()                 // 按当前 NSScreen.screens 每屏建一个窗口
    let screens = NSScreen.screens
    for (index, win) in windows.enumerated() {
        let screen = screens[index]
        win.setFrame(screen.frame, display: false)   // 精确铺满该屏
        if isPrimaryScreen(screen) {                 // 坐标原点==0 那屏 = 主屏
            updateContent(window: win, ...)          // 主屏：完整界面
        } else {
            updateSecondaryBackground(window: win, screen: screen)  // 副屏：纯背景
        }
        win.orderFrontRegardless()                   // 强制置顶（副屏也显示）
    }
}
```

- **主屏判定**：`screen.frame.origin == .zero`（带菜单栏、坐标原点那块）。`NSScreen.main` 是键盘焦点屏，不能用。
- **副屏背景**：按屏幕横竖选择 `background.png`（横）/ `menu_bg.png`（竖）。
- **窗口属性**：`level = .screenSaver`、`isOpaque = false`、`ignoresMouseEvents = false`（挡住点击）、`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`。
- **坐标坑**：不要用 `NSWindow(contentRect: screen.frame, ..., screen: screen)`，否则非主屏(Retina)坐标会被重复计算。改用 `.zero` 创建 + `setFrame(screen.frame)`。

## 四、已修坑点

| # | 问题 | 修复 |
|---|------|------|
| 1 | 循环跑一轮就停 | `task.run()` 必须在 `terminate(nil)` 之前 |
| 2 | 菜单关闭后倒计时不动 | Timer 加进 `RunLoop.main` 的 `.common` 模式 |
| 3 | 后台触发毛玻璃不弹出 | `showBreakOverlay()` 开头 `NSApp.activate(ignoringOtherApps: true)` |
| 4 | 倒计时跳秒 | 用绝对时间 `endDate.timeIntervalSince(Date())`，不累减 |
| 5 | 副屏/平板不显示遮罩 | 每屏各建窗口 + `setFrame(screen.frame)` + `orderFrontRegardless()` |

## 五、红线（不要改）

- `onDismiss` 中 bash 与 terminate 的顺序。
- `-autoRestart` 检测、2 秒自动启动、keep-alive 保活窗口。
- 窗口的 `.screenSaver` 级别、`isReleasedWhenClosed`、`collectionBehavior`。
